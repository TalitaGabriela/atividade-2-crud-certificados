# Atividade 2 - Gerenciador de Certificados (CRUD em Python)

Projeto desenvolvido como avaliação de uma disciplina anterior do curso, cursada como dependência (DP) neste semestre.

## Descrição

Sistema de linha de comando em Python para gerenciar certificados de cursos, com persistência dos dados em arquivo de texto (`certificados.txt`).

Funcionalidades:

- Cadastrar certificado
- Listar certificados
- Buscar certificado por id (busca binária)
- Buscar certificados por instituição
- Listar certificados concluídos
- Calcular carga horária total
- Alterar situação (concluído / não concluído) de um certificado
- Buscar certificados por carga horária mínima
- Exibir o certificado com maior carga horária

## Como executar

```bash
python crud_certificados.py
```
